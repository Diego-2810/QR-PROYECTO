# QR Profile - Multi-Language Portfolio
Un sistema backend diseñado para servir un perfil profesional dinámico a través de un código QR, permitiendo a los usuarios seleccionar el idioma de visualización.

## 🚀 Arquitectura y Tecnologías
- **Backend:** C#, ASP.NET Core (Minimal APIs)
- **Base de Datos:** MySQL
- **Acceso a Datos:** Dapper (Patrón Repositorio y Capa de Servicios asíncrona)
- **Frontend:** HTML5, CSS3, Bootstrap 5

## 📂 Estructura del Proyecto
El proyecto separa claramente la lógica de negocio del acceso a datos mediante el uso de interfaces y repositorios.
